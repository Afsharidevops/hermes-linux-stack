# Hermes Execution Broker v0.1.2 Release Notes

Companion security-boundary release for Hermes Linux Stack v0.5.7.

## Added

- `admin` mode for narrowly scoped execution configuration;
- exact-origin CORS and separate Execution Admin authentication;
- live feature-policy and policy-generation files;
- numeric approver allowlist management with Hermes-user subset enforcement;
- write-only dedicated Telegram approval-bot token replacement;
- Hermes-bot token hash comparison to prevent accidental token reuse;
- broker control-secret rotation;
- SSH profile metadata/status exposure without private credentials;
- execution-admin audit trail.

## Preserved trust separation

- approver mode alone retains the Ed25519 private approval signing key;
- Docker mode alone retains Docker socket authority;
- SSH mode alone retains SSH credential/profile authority;
- admin mode receives none of those authorities.

Any policy mutation increments the generation so an older pending capability or approval cannot survive a policy change.
