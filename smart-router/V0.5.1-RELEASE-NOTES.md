# v0.5.1 release notes

This release is the requested “v5.1” continuation of the repository's existing `v0.5.0` naming, therefore the package/image tag is `0.5.1`.

### P0
- Dynamic gateway route profiles and live model discovery.
- Expanded observability/control panel.
- Benchmark v0.5.1 reporter.
- Multi-user RBAC and authentication.

### P1
- Knowledge/RAG and persistent memory.
- Budget/cost governance.
- Guardrail policy engine.
- Agent profiles and improved admin UX.

### P2
- Agent-team orchestration.
- Plugin/tool registry.
- Virtual keys and quotas.
- Audit logs.
- PostgreSQL-backed shared control plane + stateless HA mode.

No raw prompt content is stored in route telemetry by the v0.5.1 extension.
