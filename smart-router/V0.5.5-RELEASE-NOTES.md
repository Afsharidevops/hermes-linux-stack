# Hermes Smart Router v0.5.5 release notes

v0.5.5 adds persisted live mode/policy/HA controls, in-place schema upgrades, group-aware ACLs, agent create/edit/delete with visible validation errors, reusable agent Skills, suggested Plugin/Skill catalogs, and built-in Operations Center documentation.

The default Operations database filename intentionally remains `control-v0.5.2.sqlite3`; `schema_versions` is upgraded to `0.5.5` and new `v55_*` tables are created in the same database.

Catalog plugin installs are registry-only and disabled by default. Assigned enabled Skills are incorporated into agent system context.
