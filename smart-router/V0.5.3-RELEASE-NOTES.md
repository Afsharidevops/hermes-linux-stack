# Hermes Smart Router v0.5.3 — Flight Deck UX

## Highlights

- New Hermes Flight Deck telemetry dashboard at `/dashboard`.
- Grouped Control Plane navigation: Observe, Routing, Access, Intelligence, System.
- Choice-driven controls use selects/dropdowns for finite values.
- Dashboard access state, time-window selection, auto refresh, measurement quality, zero-state guidance, and explicit pricing warnings.
- Control Plane retains all v0.5.2 features and persisted data.

## Persistence compatibility

v0.5.3 intentionally keeps the v0.5.2 Control Plane database/schema identifier (`control-v0.5.2.sqlite3`) so an in-place upgrade does not create a second empty database or discard existing users, keys, routes, budgets, policies, knowledge, memory, agents, teams, plugins, ACLs, audit records, or outcomes. This is a compatibility detail, not the runtime version.
