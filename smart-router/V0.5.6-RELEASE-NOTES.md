# Hermes Smart Router v0.5.6 Release Notes

This release introduces hybrid/vector RAG, request traces, guardrails, router pipelines, platform registries, UI lifecycle consistency, and HA validation examples.

The default Operations Center database URL remains `sqlite:////data/control-v0.5.2.sqlite3`; the schema marker upgrades in place to `0.5.6`.

## UI lifecycle fixes

Enable/Disable is reversible and changes the visible state immediately. Delete/Permanent Delete is destructive and separate. Teams now validate referenced Agent IDs and support edit/enable/disable/purge. Groups protect ACL references on purge. Routes, Skills, Plugins, and Agents show consistent active/enabled actions.

## RAG

`SMART_ROUTER_RAG_MODE=hybrid` combines lexical and vector scores and applies a lightweight rerank. PostgreSQL deployments can use pgvector. Set `SMART_ROUTER_EMBEDDINGS_BASE_URL` and `SMART_ROUTER_EMBEDDINGS_MODEL` for a real OpenAI-compatible embeddings service.

## Guardrails

`SMART_ROUTER_GUARDRAILS_MODE=audit` is the safe migration default. Use `enforce` only after reviewing findings and tool policy in your environment.

## Enterprise identity scope

OIDC is the interactive login implementation. The new Identity page exposes LDAP/SAML/SCIM configuration readiness, but those integrations are not claimed production-complete in v0.5.6.
