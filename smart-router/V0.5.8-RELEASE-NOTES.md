# Hermes Smart Router v0.5.8 Release Notes

Hermes Smart Router v0.5.8 adds a visual Operations Center building experience across the supported gateway branches while preserving the existing routing, access, RAG, guardrail, and execution trust boundaries.

## Highlights

- Visual Workflow Studio with draggable graph nodes and persisted graph metadata.
- Visual Agent Studio for knowledge/tool/instruction configuration.
- Visual Router Pipeline Studio for validated routing stages.
- New Knowledge Pipeline Studio plus `v58_knowledge_pipelines` persistence/API.
- New Publish & Monitor workspace.
- Reorganized Build/Tools/Routing navigation.
- Substantially improved light theme for Operations Center and Flight Deck.
- Execution & Approvals connection diagnostics distinguish network/CORS/bind failures from an invalid key.

## Compatibility

- Runtime/control schema: `0.5.8`.
- Existing compatibility DB filename: `control-v0.5.2.sqlite3`.
- Persistent state is upgraded in place; do not delete `data/smart-router/` during a normal upgrade.
- Companion Execution Broker target: `0.1.3`.

The visual graph registries define and review orchestration metadata. They do not by themselves grant host Docker/SSH authority or bypass ACLs, guardrails, execution approvals, or API authentication.
