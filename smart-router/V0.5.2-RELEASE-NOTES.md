# Hermes Smart Router v0.5.2 release notes

This package implements the v0.5.2 reliability/security foundation while keeping the OpenAI-compatible `/v1` API and v0.5.1 local/SQLite mode backward compatible.

Implemented in this package:

- provider/model health registry and database-shared circuit breakers;
- safe upward fallback when a selected route circuit is open;
- optional Redis shared rate-limit counters for HA deployments;
- file/Docker-secret loading through `*_FILE` with ambiguity checks;
- generic OIDC authorization-code login with signed state/nonce validation and group-to-role mapping;
- external identity provisioning and immediate session invalidation when a user is disabled;
- server-side session logout/revocation;
- resource ACL table/API and ACL-aware knowledge retrieval;
- knowledge-source hash deduplication and replace-on-reindex semantics;
- `/router/info`, upgraded readiness, provider-health API, and Prometheus metrics;
- schema version tracking for non-destructive v0.5.2 startup migration.

The larger v0.5.2 plan still contains release gates that require external infrastructure and evidence (LDAP/SAML, pgvector/Qdrant connectors, full Helm production validation, 10k+ held-out benchmark, multi-node fault testing). They are tracked in `docs/HERMES-SMART-ROUTER-v0.5.2-PLAN.md` and are not falsely marked as proven by this source-only package.
